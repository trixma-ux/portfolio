# Portfolio de Gomon Steve

Portfolio professionnel présentant mon profil de Key User SAP PM et développeur web/mobile.

## Déploiement

Ce site est prêt pour GitHub Pages.

1. Allez dans **Settings** > **Pages** du dépôt.
2. Sous **Build and deployment**, sélectionnez **Deploy from a branch**.
3. Choisissez la branche **main** et le dossier **/** (root).
4. Enregistrez. Le site sera disponible à : https://trixma-ux.github.io/portfolio/
